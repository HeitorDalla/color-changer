# Trocador de Cores
Esse é um projeto de Trocador de Cores. O software muda de cor a cada click que você der no trocador!

## Tecnologias utilizadas
Essse projeto foi desenvolvido seguindo as seguintes tecnologias:

- HTML - Estrutura o layout da página (https://html.com/) 
- CSS - Estiliza o layout (https://css.com/)
- JavaScript - Implementa a lógica de trocar as cores conforme clique do usuário (https://www.javascript.com/)

## Visualização do Projeto
(https://heitordalla.github.io/color-changer/)

## Funcionalidades
-Troca as cores conforme clique do usuário
  
## Como Usar
1. Abra o arquivo index.html em seu navegador da web.
2. Clique em trocar cores

## Pré-requisitos
Não há pré-requisitos específicos para utilizar este gerador de senha.
